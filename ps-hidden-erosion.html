Problem Space 3 of 7 · Hidden erosion

Is margin being consumed while output holds steady?

A system can keep delivering its output while the structural margin behind that output is being used up. The instrument reads remaining margin alongside observed output, so the gap between them becomes visible while there is still time to act. That gap is the precursor window.

You'll recognize this if targets keep being met, but each month it takes more effort, more overrides or more spare capacity to meet them.

What you receive

Remaining structural margin read as of each date, set against observed output.

When to use it

When output looks stable but the cost or effort of keeping it there is rising.

What it starts from

Repeated, time-stamped records of the system and its relationships.
