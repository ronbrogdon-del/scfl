Method

How the presentation values are calculated

Every value above follows this recipe, using public data only. It is a proxy for traffic conditions and contains no SCFL operators.

FOR each chokepoint c:
  daily      = PortWatch transits per day (all ship types)
  current    = average of daily over the latest 7 days
  reference  = median of 7-day averages, 1 Jan – 31 Dec 2025
  flow       = current / reference      # 1.00 = typical

  mix_now    = share of each ship type, latest 28 days
  mix_ref    = share of each ship type, 2025
  mix_shift  = ½ × Σ |mix_now − mix_ref|

  state = Normal flow       if flow ≥ 0.90
          Reduced flow      if 0.60 ≤ flow < 0.90
          Constrained flow  if 0.20 ≤ flow < 0.60
          Near-closed       if flow < 0.20
NETWORK FLOW INDEX
  weight(c) = average daily tonnage of c in 2025
  index     = 100 × Σ weight(c) × flow(c)
                  / Σ weight(c)

REROUTING SIGNAL (Suez ↔ Cape of Good Hope)
  shown if  one flow < 0.90
       and  the other flow > 1.10

Data:  IMF PortWatch Daily Chokepoints Data

Notes

Not a forecast or an alarm. Flow states describe current traffic only. They say nothing about what happens next.

Note on terminology. Earlier UCMS maritime work, including the HCDI 1.2 paper, used the phrase "public early-warning layer." That wording was not intended to describe an early-warning system (EWS). It referred to a structural layer reading only.

Data limits. PortWatch figures come from vessel AIS signals and are published with a delay of several days. Ships that switch off transponders may be undercounted.
