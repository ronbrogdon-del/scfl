# Standard Coherence Fidelity Layer (SCFL)

SCFL is an independent research program investigating whether the relationships that hold complex systems together remain intact under stress.

## About

**Originator:** Ronald L. Brogdon

**Core definition:** "Coherence is the degree to which a system's relationships hold one another in place."

**Objective:** To develop an upstream measurement approach that complements existing performance indicators and analytical frameworks, identifying relational integrity before system failure occurs.

## Publishing

To publish this site via GitHub Pages:

1. Go to **Settings** → **Pages**
2. Under **Build and deployment**, select **Deploy from a branch**
3. Select the **main** branch and the **/ (root)** folder
4. Click **Save**
5. GitHub will deploy the site and provide a URL

Design is fully responsive and tested on desktop and mobile widths.
