# SCFL Research

This repository contains a simple landing page for the SCFL research project.

## Files

- `index.html` — Homepage structure and content
- `style.css` — Responsive styling for desktop and mobile layouts
- `script.js` — Small script for the current year and UI behavior

## Before publishing

Update the following values to match your final project details:

- The research reference link in `index.html`
- The contact email address in `index.html`
- Any project copy, background text, or headings needed for publication

## Local preview

Open `index.html` in a browser, or serve the directory with a local static server if desired.
